# KKCD 2025 Economic Impact Analysis

## Project Overview
This project analyzes the economic impact of the **Kota Kinabalu Countdown (KKCD) 2025** event, a New Year's Eve celebration organized by the Sabah state government. 

The analysis quantifies the event's **economic multiplier effect** on Sabah's tourism ecosystem, including direct revenue (government grants, ticket sales, sponsorships) and indirect revenue (tourist spending).

**Key Finding:** Every RM 1 invested in KKCD generated **RM 3.05** in total economic activity (**3.05x multiplier**).

---

## Objectives
- Calculate total event costs and direct revenue
- Estimate indirect revenue from tourist spending
- Assess whether the event generated a positive economic return

---

## Key Metrics

| Metric | Amount |
|:-------|-------:|
| Total Cost | RM 6,147,257 |
| Direct Revenue | RM 6,153,891 |
| Indirect Revenue (Tourist Spending) | RM 12,580,890 |
| **Total Economic Impact** | **RM 18,734,781** |
| **Economic Multiplier** | **3.05x** |

## Limitations
- Tourist spending used **state/national averages** due to lack of individual-level data
- Hotel accommodation revenue **excluded** due to incomplete data
- Attendance figures are **survey-based estimates**
